# 广场书本阅读

公开书籍页点击「📖 书本阅读」进入分页阅读；原有 Markdown 预览仍可使用。

- 支持单页、双页，窄于 900px 自动使用单页，保留双页偏好。
- 可设置向左、向右、上下翻页，字号、行距、衬线/无衬线字体及暖纸、白纸、护眼、夜间主题。
- 按钮、方向键、PageUp/PageDown、空格可翻页；Home/End 跳转本章首尾。章末继续进入下一章，回翻返回前章末尾。
- 目录可跳章，进度条可跳页；Esc 先关闭设置/目录，再退出阅读。支持专注模式与减少动态效果偏好。
- 触屏支持按设定方向滑动，上下模式支持滚轮。代码、表格保留内部滚动，不拦截文字选择。
- 设置保存在当前浏览器；阅读位置按分享 ID 和发布版本隔离。更改字号、窗口大小时按文字位置重新排版；新发布版本不复用旧版本进度。禁用本地存储时仍可阅读。

实现：阅读器延迟加载，CSS 多栏对经过净化的 Markdown 实际排版，ResizeObserver 与字体/图片加载触发重排。不修改书籍正文、数据库或模型配置。

验证：设置/进度纯逻辑测试、全量项目测试与构建通过；本地合成三章书籍完成桌面单双页、换章、方向键、字体/主题、续读、目录、键盘焦点及 375/768px 窄屏检查，浏览器无控制台错误。触屏手势已实现，尚未在真实手机硬件上验证。

# 产品设计：Aicho Muse

## 1. 愿景

每个人都有想写却写不出来的故事。Aicho Muse 的目标是让创作回归"说话"——像和朋友聊天一样，把脑子里模糊的念头说出来，在助手的提问、反馈和鼓励中，一点点变成完整的作品。

> 一句话：**一个会聊天、有性格、有声音的写作教练。**

## 2. 目标用户

- **想写自传/回忆录的人**：有经历但不知从何下笔，需要引导性提问和整理。
- **文学爱好者/业余作者**：写小说、散文、诗歌，需要灵感启发与修改建议。
- **创作者新手**：不熟悉写作技巧，需要鼓励式陪伴与结构化流程。
- **忙碌的讲述者**：习惯用语音表达，希望"口述成文"。

共同点：**不是要一个自动写文章的机器，而是需要一个能对话、懂自己的创作伙伴。**

## 3. 核心场景与用户旅程

### 场景 A：口述自传

1. 用户选择/创建一位"倾听者"人设（如温和的老朋友）。
2. 新建作品《我的前半生》，设定主题与时间范围。
3. 用户开始口述："我小时候在江南一个小镇上长大……"
4. 助手一边整理要点，一边追问："那时候最让你难忘的一个画面是什么？"
5. 多轮对话后，助手自动把零散口述整理成结构化章节草稿。
6. 用户逐章过目、语音或打字修改，助手给出润色建议。
7. 完成后一键导出为 Markdown / PDF。

### 场景 B：小说创作陪跑

1. 用户选择"严苛编辑"人设，获得有挑战性的反馈风格。
2. 助手先通过对话帮助用户明确：故事内核、主角目标、冲突。
3. 用户提出场景想法，助手给出"这个冲突不够"的具体反馈。
4. 创作进入瓶颈时，助手用提问引导而非直接代写。
5. 每章完成后获得"编辑点评"与下一步建议。

### 场景 C：碎片灵感收集

- 随时随地口述一个点子，助手记录、归类到对应项目，并在下次对话时带回来。

## 4. 核心功能设计

### 4.1 助手系统（Persona + Voice）

- **人设**：姓名、背景故事、性格特质、说话风格、价值观、与用户的关系、擅长领域。
- **声色**：音色（TTS 引擎与音色 ID）、语速、音调、情绪表达强度、口头禅/语气词。
- **预设库**：内置多种文艺人设（温柔倾听者、严苛编辑、灵感缪斯、旅行作家等），一键启用后可深度自定义。
- 详见 [人设与声色系统](VOICE_PERSONA.md)。

### 4.2 创作项目（Project）

作品是一等公民：

- 项目元信息：标题、体裁（自传/小说/散文/诗歌/剧本）、主题、目标读者、创作目标（如 3 万字）。
- 结构管理：大纲 → 章节 → 段落；人物设定卡；时间线；灵感碎片箱。
- 自动保存与版本历史：每次对话后的草稿变化都可回退。
- 导出：Markdown、纯文本（后续 PDF / DOCX）。

### 4.3 对话式创作（核心交互）

输入方式：语音（STT）或打字，等价。

助手的四种回应类型：

| 类型 | 目的 | 示例 |
| --- | --- | --- |
| 提问 | 引导用户展开 | "当时你在想什么？" |
| 反馈 | 评价已有内容 | "这段对话很生动，但冲突可以更早出现。" |
| 建议 | 给出可执行方向 | "试试把视角换成配角。" |
| 鼓励 | 维持创作动力 | "今天已经写了 800 字，比昨天进步了。" |

关键原则：**默认引导而非代写**。用户主动要求时，助手才提供扩写/续写/润色。

### 4.4 写作工具

- 润色（保持原意、提升表达）
- 扩写 / 缩写
- 续写（基于上下文，用户可选择接受）
- 风格迁移（如"改成张爱玲式的冷峻笔调"）
- 一致性检查（人物、时间线、设定冲突提醒）

### 4.5 记忆系统

- **会话记忆**：当前对话上下文。
- **项目记忆**：作品设定、人物、已定稿章节。
- **用户记忆**：写作偏好、常用题材、希望被怎么鼓励。
- 存储策略：结构化数据 + 向量检索（RAG），跨会话可用。

## 5. MVP 范围

### 包含

- Web 应用（响应式，可安装为 PWA）
- 打字对话 + 语音回复（TTS 播放）
- 3 个预设人设 + 人设编辑器（文字部分）
- 单个/多个创作项目、章节编辑、自动保存
- 助手四种回应类型的基础实现
- 导出 Markdown

### 暂不包含（放入后续里程碑）

- 语音输入（STT）、声音克隆、多人设音色库
- RAG 长期记忆、写作工具全家桶
- 移动端原生封装

## 6. 设计原则

1. **聊天优先**：一切功能尽量从对话里自然发生，不强迫用户学习复杂界面。
2. **人设一致性**：同一个助手，在不同设备、不同时间，性格与声音要稳定。
3. **创作主权在用户**：AI 是教练不是代笔，所有成稿决定权在用户。
4. **隐私安全**：创作内容是高度私密的，加密存储、最小权限、可随时删除。
5. **厂商无关**：LLM / STT / TTS 均可插拔，避免被单一供应商锁定。
6. **渐进可用**：打字先行、语音后上；没有高级功能时核心体验依然完整。

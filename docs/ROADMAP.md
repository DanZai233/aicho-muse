# 路线图：Aicho Muse

## M0 — 设计验证（当前）

目标：把"语音创作缪斯"讲清楚、跑通核心交互。

- [x] 项目命名与品牌定位（Aicho Muse / 声创）
- [x] 产品设计、架构、人设声色、路线图文档
- [x] 可交互打字原型：单会话 + 一个预设人设 + 简单项目概念
- [x] 验证核心对话体验：提问式引导是否让用户写得更顺畅（SSE 实测引导回复）

**验收**：陌生用户拿到原型，无需说明就能完成一次"口述一小段经历 → 得到提问与鼓励"。

## M1 — MVP（Web）

目标：可日常使用的单用户 Web 应用。

- [x] 响应式 Web + PWA 基础
- [x] 账号系统（邮箱登录）
- [x] 打字对话，SSE 流式输出
- [x] 3–4 个预设人设 + 人设编辑器
- [x] 语音回复：接入至少一家 TTS，可播放/倍速
- [x] 创作项目：新建、章节编辑、自动保存
- [x] 导出 Markdown
- [x] 基础限流与隐私说明

**验收**：用户能创建自定义人设，完成一个 3–5 章的短篇或自传初稿，并导出为 Markdown。

## M2 — 语音闭环

目标：语音成为与打字平等的主流输入方式。

- [x] 语音输入：STT 接入（优先中文识别质量）
- [x] 全链路语音对话（说 → 转写 → 回复 → 朗读），支持打断
- [x] 项目结构增强：大纲、人物卡、时间线、灵感碎片箱
- [x] 写作工具：润色、扩写、续写、风格迁移
- [x] 回复类型可观测（提问/反馈/建议/鼓励 的统计与调优）
- [x] 版本历史与回退

**验收**：用户可以在通勤路上用语音口述一整章，回家后在电脑上继续完善。

## M3 — 智能增强与生态

目标：让助手"记得你"，并支持更丰富的创作生态。

- [x] RAG 长期记忆（简化版）：偏好、设定、人物关系跨会话延续（importance 排序注入 top-5）
- [x] 声音克隆框架（授权制：样本上传+授权声明+克隆服务可配置接入）；实际克隆依赖 Fish Audio 等外部服务 Key
- [x] 多人设团队模式（编辑 + 读者 + 导师 同时陪跑，作品绑定团队 + 会话切换）
- [x] 一致性检查（人物/时间线/设定冲突提醒）
- [x] 导出 PDF / DOCX（中文渲染修复）；云端多设备同步（自托管 Docker + MySQL 持久化）
- [x] 社区分享：人设与音色搭配（公开库 + 一键收藏克隆）

**验收**：三个月后重新打开一个旧项目，助手仍然记得关键设定与用户的写作偏好。

## M4 — 探索项（已完成）

目标：把 M0–M3 之外的想象力补成可用的能力。

- [x] 个人写作报告：作品/章节/字数/创作天数/会话统计，体裁分布、高频主题词、写作工具与回复类型分布、记忆偏好摘要（设置页「创作足迹」，实测闭环）
- [x] 多语言创作：作品语言字段（简体/繁体/英/日/韩/法/德/西/俄），AI 按作品语言对话与建议，创建/设置页可切换（英文实测闭环）
- [x] 团队协作创作：邀请码加入，owner/editor/viewer 权限分层，全路由读写校验，协作者管理（改角色/移除，实测闭环）
- [x] PWA 完善：离线页 + 导航失败回退、安装提示条（beforeinstallprompt）、PNG/maskable 图标 + apple-touch-icon

**验收**：四项探索能力均已端到端实测闭环，功能总览与部署文档同步更新。

## 后续探索（非承诺）

- 桌面 / iOS / Android 封装
- 协作者实时光标与评论批注
- 基于创作数据的进阶分析（写作节奏、情绪曲线）
- 更多语种的本地化界面

## M5 — 文稿导入与论文写作（已完成）

目标：把已有的未完成作品带进来继续写，并支持学术论文这一独立体裁。

- [x] 文件导入：Word（.docx）/ Markdown（.md）/ 纯文本（.txt），自动按标题切分章节；新建作品或追加到已有作品（续写未完成稿）
- [x] AI 后处理：导入后可选让 AI 生成大纲（大纲面板）与提取设定/背景知识（记忆知识库，助手自动参考）
- [x] 论文体裁：独立工作区（摘要、关键词、引用格式），左侧「文献」面板管理参考文献，正文光标处插入 [n] 标注
- [x] 论文助手提示词：学术语气、结构引导（摘要→引言→文献综述→方法→结果→讨论→结论）、引用规范（GB/T 7714 / APA / MLA）
- [x] 论文导出：MD / DOCX / PDF 自动带摘要、关键词与文末参考文献列表

**验收**：md/docx/txt 三种格式导入、追加续写、AI 大纲与知识库提取、论文项目创建、引用增删改、正文 [n] 插入、三种导出均已实测闭环。

## 里程碑决策点

每个里程碑结束前需要确认：

1. 核心指标是否达标（如"引导后用户继续创作的对话占比"）。
2. 语音质量是否达到"愿意听完整段回复"的水平。
3. 人设一致性是否稳定（换设备、换会话后体验一致）。
4. 成本是否可控（token 与 TTS 单用户月成本）。

# 人设与声色系统

助手 = **人格（怎么想、怎么说）** × **声音（怎么发声）**。二者分离配置、可自由组合，是 Aicho Muse 最具差异化的部分。

## 1. 人设卡（Persona Card）

一个助手的人设由一张结构化的"人设卡"定义：

```json
{
  "id": "persona_liwen",
  "name": "黎文",
  "tagline": "安静的倾听者",
  "avatar": "liwen.png",
  "background": "当过十二年文学编辑，现在开一间小书店，喜欢听人讲故事。",
  "personality": ["温和", "耐心", "敏锐", "不评判"],
  "speaking_style": {
    "tone": "平静而温暖",
    "preferences": ["多用提问引导", "少用绝对化结论", "偶尔引用一句诗"],
    "avoid": ["说教", "过度夸奖", "替用户做决定"]
  },
  "values": ["真实比华丽重要", "创作是自我发现的过程"],
  "relationship": "亦师亦友的编辑",
  "expertise": ["叙事结构", "人物塑造", "回忆录写作"],
  "greeting": "今天想讲点什么？我在听。"
}
```

### 人设字段说明

| 字段 | 作用 |
| --- | --- |
| `background` | 让助手有可信的"来处"，影响语言习惯与知识倾向 |
| `personality` | 性格特质列表，进入系统提示词 |
| `speaking_style` | 语气、偏好、禁忌，直接约束回复风格 |
| `values` | 价值观，用于反馈建议的立场基准 |
| `relationship` | 与用户的关系定位（朋友/编辑/导师），决定亲密度与分寸 |
| `expertise` | 可强调的专业视角 |

## 2. 声色卡（Voice Profile）

```json
{
  "id": "voice_liwen",
  "display_name": "黎文 · 温润男声",
  "provider": "volcengine",
  "voice_id": "volc_xxxxxxxx",
  "params": {
    "rate": 0.95,
    "pitch": 0,
    "emotion": "warm",
    "energy": 0.6
  },
  "speech_notes": "语速略慢，句尾轻柔收束",
  "features": ["neural", "multi_emotion"]
}
```

### 参数映射

应用层定义**与厂商无关的语义参数**，由适配器翻译成各家 TTS 的实际参数：

| 语义参数 | 含义 | 示例值 |
| --- | --- | --- |
| `rate` | 语速倍率 | 0.85–1.15 |
| `pitch` | 音调偏移 | -2 … +2 |
| `emotion` | 情绪基调 | warm / calm / energetic / serious |
| `energy` | 表达强度 | 0.2–1.0 |

同一"黎文"人格可以搭配不同音色；不同人格也可以共用一套音色参数。

## 3. 运行时组装

每次生成回复时，后端将人设卡 + 声色卡的说明编译进上下文：

```text
【你是黎文。】你当过十二年文学编辑……
【说话方式】温和、耐心，多用提问引导；不说教，不替用户做决定。
【本次任务】用户在创作自传《我的前半生》，当前章节：童年。
【创作准则】先反馈具体感受，再给一条可执行的建议，最后用一句话鼓励。
```

TTS 侧按声色卡参数合成语音；文本侧始终保留完整表达（语音是对文本的"口语化演绎"，二者不互相损失信息）。

## 4. 预设人设库（M1 提供）

| 预设 | 一句话定位 | 性格关键词 | 建议音色 |
| --- | --- | --- | --- |
| 黎文 | 安静的倾听者 | 温和、耐心、敏锐 | 温润男声 |
| 苏禾 | 灵感缪斯 | 浪漫、跳跃、诗意 | 清亮女声 |
| 陈墨 | 严苛编辑 | 犀利、直接、专业 | 低沉中性声 |
| 阿岛 | 旅行作家 | 好奇、幽默、随性 | 元气男声 |

所有预设均可二次编辑，也可另起炉灶自定义。

## 5. 高级方向（M3+）

- **声音克隆**：用户授权后，用少量样本复刻自己的声音或喜欢的音色。
- **音色市场**：社区分享人设卡与音色搭配（明确版权边界）。
- **情绪化实时演绎**：根据文本情绪自动切换 TTS 情绪参数。
- **口述风格学习**：学习用户的口头表达习惯，让整理后的文字更"像本人"。

## 6. 合规与伦理

- 声音克隆必须取得明确授权，提供"立即下线"机制。
- 人设不得冒用真实在世人物身份（默认）；名人/版权音色不进入官方预设。
- 助手的人设信息对用户透明，可随时查看当前角色配置。

# 编辑保存修复（2026-10-14）

章节标题与正文使用同一个按章节串行的保存队列。保存完成前的新输入保留在本地草稿；迟到的项目请求、协作通知不能覆盖本地编辑。保存失败显示重试入口，服务端内容变化返回 409，用户核对后才能明确覆盖。

协作只通知已持久化的章节，客户端重新读取授权接口；不在加入房间时回放临时正文。切换章节销毁旧连接，当前用户不显示为远端协作者。

润色等改写明确替换正文，续写追加；取消替换不修改正文。采纳和改写携带生成/提交时的正文基线，避免覆盖期间发生的修改；原文保留版本历史。

验证：`npm test` 覆盖延迟保存、新输入、迟到读取、冲突、章节切换、改名、正文替换和持久化协作通知；`npm run build` 校验 TypeScript 和生产打包。

## 正文

写小说/自传总是卡在开头？今天想认真写点东西，结果打开文档半小时只憋出两行字……

我把这个困扰做成了产品 👇

📖 Aicho Muse · 声创 —— 一个会陪你写作的 AI 创作伙伴

它不是一个「生成器」，更像一位真正的创作搭子：

🎙 语音口述创作
想到什么说什么，语音自动转文字。洗澡时灵光一闪，回来就能在纸上接着写。

🧑🎨 人设、性格、声色全部自定义
你可以定义它的性格、说话方式、价值观、口头禅，甚至绑定一个喜欢的音色。喜欢「温柔安静的编辑」还是「毒舌犀利的老友」，都随你。

✍️ 写作 Agent 工作流
不是一问一答那么简单：它会提问引导你理清思路 → 给反馈 → 给出写作稿 → 用 diff 标出可采纳的新内容，你一键决定「采纳」还是「忽略」。AI 写的内容永远不会悄悄改你的稿子。

📚 一本书从封面慢慢长出来
章节、大纲、人物卡、时间线、灵感箱、角色关系图，全部结构化。写完还能导出 Markdown / PDF / Word。

🗣 声音也是创作的一部分
接入了 Fish Audio 音频广场，83 种语言、上千个音色可搜索试听收藏；也可以克隆自己的声音，让「缪斯」用你的声音朗读你的故事。

🌐 支持多人协作
和朋友一起写剧本？邀请码加入，实时看到对方的光标位置，一起创作。

还有「拾卷」广场——把作品某一刻的快照分享出来，像一本还在连载的书。

开源项目，技术栈 React + Node.js + MySQL，Docker 一键部署，AI 支持 DeepSeek / OpenAI / Claude / 通义 / 豆包等 14+ 家模型。

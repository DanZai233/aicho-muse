# 大纲策划与正文写作

## 用户流程

作品设置和新建/导入支持：生活指南、心理与自我关怀、纪实非虚构、随笔杂文、科普、旅行与城市漫游，以及原有文学与论文类型。

在工作台选择「大纲 → 规划大纲」，先填写目标、读者、口吻，以及可选覆盖范围和禁区，再生成详细大纲。用户可以编辑每章标题和说明，选择章节追加到作品；已确认的写作约定随作品保存，下次策划和正文生成复用。

每个大纲节点可点击「写正文」。生成时结合全书目录、写作约定、人物设定和前章结尾。正文先预览，可修改，确认后创建独立的新章节；已有章节保留。如果节点没有关联章节，会关联新章节。生成到保存之间大纲变化会返回 409，保留当前预览供核对。

## 404 修复

原 AI 建议格式允许 `type=update`，但没有向模型提供实际条目 ID，前端直接 PATCH 生成的 ID 或空 ID。现在上下文提供真实 ID，服务端归一化并使用作品内真实条目核验。找不到目标的调整明确改为新增；跨作品 ID 不能修改其他作品。统一采纳接口使用 suggestion_id 去重；大纲批量添加和正文采纳也各自以草稿标识去重，前端操作期间禁用重复提交。

## 验证

`npm test`：原编辑保存回归 + 真实 HTTP 测试覆盖无效/缺失/跨作品建议 ID、重复采纳、访谈必填、无副作用预览、原文保留、大纲变更冲突、读者/陌生人权限和新增体裁。测试模型使用本地注入，不调用付费服务。

`npm run build`：TypeScript 和 Vite 生产构建。

本地隔离数据与模拟模型的浏览器验证覆盖：登录、填写访谈、编辑大纲预览、批量添加、按节点写正文、预览和采纳、刷新后原文和写作约定仍保留。布局检查宽度 375、768、1440。无既有截图基线，不声称完成视觉回归或完整无障碍认证。

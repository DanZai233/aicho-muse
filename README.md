# Aicho Muse · 声创

> 用对话和声音，把灵感写成作品。

Aicho Muse 是一款面向创作场景的 AI 创作伴侣：你可以通过 **语音或打字** 与一位 **人设、性格、声色完全自定义** 的 AI 助手对话，在聊天的过程中完成小说、散文、个人自传、诗歌等文学作品的创作。助手不只是"生成器"，更是你的**陪写教练**——给你反馈、建议、鼓励，陪你一步步把作品打磨成型。

## 项目定位

- **通用 Web 应用（响应式 / PWA）**：手机、平板、电脑浏览器都能用，后续可封装为桌面或移动应用。
- **语音优先，文字平等**：口述灵感、语音提问、听助手回复；没有麦克风时打字同样完整可用。
- **人设 + 声色双自定义**：助手可以有自己的人格、说话风格、价值观，也有匹配的音色、语速和情绪表达。
- **创作工作流**：围绕"作品"组织会话——创建项目、构建大纲、逐章推进、润色修改、一键导出。
- **与 Aicho 家族统一**：沿用 aicho.chat 品牌（Aicho ≈ AI + Echo），与已有的 AI 情感日记应用形成"日常陪伴 + 创作陪伴"的产品矩阵。

## 核心特性

| 模块 | 说明 |
| --- | --- |
| 对话式创作 | 用自然对话推进作品，助手提问、启发、反馈、鼓励 |
| 自定义人设 | 姓名、背景、性格、说话风格、与你的关系，均可配置 |
| 自定义声色 | 音色、语速、音调、情绪化表达；支持接入多种 TTS 引擎 |
| 语音交互 | 语音输入（STT）+ 语音回复（TTS），全链路可配置 |
| 创作项目管理 | 多作品、分章节、大纲与人物设定、自动保存与版本历史 |
| 智能写作工具 | 润色、扩写、改写、续写、风格迁移 |
| 长期记忆 | 记住你的偏好、作品设定与人物关系，跨会话延续 |
| 多端适配 | 响应式 Web + PWA，移动端触屏与桌面键鼠体验 |
